# mescogss-site

MESCO GSS website, built by Bidaya. One Vercel project, two sites:

- `/` — the redesign. Same wording, palette, fonts, logo and images as the original; new layouts and transitions. Generated by `python3 build.py` from `content.py` (verbatim copy) — edit those, rebuild, commit.
- `/old/` — the original WordPress/Elementor site exported to static HTML, exactly as it was live (reference only; forms are inert).

Static files only, no build step on Vercel.
